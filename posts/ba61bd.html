用python玩转数据_day01

发表于2026-05-22|更新于2026-05-22|学习笔记Python
|浏览量:

起因

最近学校要求在网上选人工智能的课，趁这个机会好好学一下python

  • 课程地址

运算符与表达式

  • 运算符要考虑运算顺序
  • python是一种动态强类型语言，不需要显示指定类型，根据值来确定类型

变量引用与内存管理

  • is操作符的使用

  • python中每个对象都有一个身份id，引用次数可以用计数器查看

  • 相同若干小整数，以及一部分常用变量可能会被分配同一内存空间

  • 同一语句块当中，相同的不可变对象不会再额外分配空间

增量赋值

数据类型

  • 在python2.2之后，整型与长整型进行了统一
  • python没有整型溢出问题
  • True :1 False:0/空列表、空元组
  • 浮点型(float)：3.22/9.8e3
  • 复数型(complex)
    • 虚数部分必须有j 2.4+5.6j
    • x.imag 取虚部
    • x.real 取实部
    • x.conjugate 取共轭复数
  • 列表和元组 分别是方括号和圆括号
  • 字符串 单引号、双引号、三引号(多行字符串，也可以自由使用单引号、双引号)
    • 可使用索引操作符 str[2]
  • 映射类型字典 用大括号鉴别 d{‘key1’,‘value1’}

基本运算

算术运算

  • 正负号 ±
  • 乘方 **
  • 乘除 */
  • 整除 //
  • 取余 %
  • 加减±

比较运算

  • 小于 <
  • 大于 >
  • 大于等于 >=
  • 小于等于 <=
  • 不等于 !=

字符串比较

按ascii码值比较

链式比较

  • 3<4<7 same as 3<4 and 4<7
  • 4>3==3 same as 4>3 and 3==3
  • 4<3<5!=2<7 same as (4 < 3) and (3 < 5) and (5 != 2) and (2 < 7)

逻辑运算

not ，and， or

字符运算

  • 操作符r/R用于一些不希望转义字符起作用的地方

python中的函数，包和库

内建函数

数值型

  • abs()
  • round() #四舍五入
  • float()
  • pow()
  • 输入dir(builtins)

标准库函数

需要先导入，比如math

  • floor() # 向下取整

第三方库函数

用户自定义函数

包和库，模块

模块->包->库

  • 模块
    扩展名为.py的为媒介
  • 包
    多个py文件集合体
    import 包/模块名称 as 自定义名称
  • 库(实际上，技术层面并无此定义)
    包的集合体

选择结构

if

标准结构

if 条件表达式:
执行代码块
elif:
else:
执行代码块

简写结构

t=1 if x>=0 else 0

循环

while

for

range(start,end,step)

  • 生成等差整数序列
  • 返回range对象
  • 不包含end
  • 缺省start值为0

自定义函数

docstring

默认参数

  • 函数的参数可以有一个默认值
  • 默认参数后面不能有非默认参数

关键字参数

  • 防止参数过多时记忆混乱
  • 位置参数不能出现在关键字参数之后

传递函数

把函数名传递给另一个函数

lambda函数/匿名函数

  • 没有return，没函数名，更加精简

变量作用域

  • 在python中，函数内部要使用全局变量要加入global 变量名

python常用标准库函数

math

  • sqrt
  • degrees
    弧度转成角度
  • radians
    角度转成弧度

os

  • getcwd()
    获取当前目录
  • chdir()
    切换目录
  • rename()
    重命名文件或者文件名
  • remove()
    删除文件
  • rmdir()
    删除文件夹

random

  • choice()
    从序列中获取随机值
  • random()
    [0-1.0)随机小数
  • uniform()
    随机浮点数
  • sample()
    从给定序列随机获取指定数量的值
  • shuffle()
    将列表中元素打乱

datetime

5个类

  1. datetime :日期+时间
  2. date: 日期
  3. time: 时间
  4. timedelta: 时间差
  5. timezone: 时区

时间戳

与时区无关

  • datetime.datetime.fromtimestamp()
  • dt.timestamp()

异常

  • try-except
